# Code of Conduct

## Our pledge

We want this project to be a welcoming place for everyone who wants to study poker, whatever their experience, background or identity.

## Expected behaviour

- Be kind and patient, especially with beginners.
- Give feedback on ideas and code, not on people.
- Accept that strategy debates have more than one reasonable answer.

## Unacceptable behaviour

- Harassment, insults, or discriminatory language.
- Publishing other people's private information, including real players' names or hand histories without consent.
- Promoting cheating, collusion, bots or real-time assistance tools.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break this code, and may block repeat offenders. Report problems by opening an issue marked "conduct" or by contacting the maintainer through their GitHub profile.

This code is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
