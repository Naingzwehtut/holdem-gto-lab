# Security policy

Hold'em GTO Lab runs entirely in the browser. It has no server, no accounts and sends no data anywhere: hand histories and screenshots are processed locally and never uploaded.

If you find a security problem, such as a crafted hand-history file that runs script in the page, please report it privately through GitHub's **Report a vulnerability** button on the repository's Security tab rather than in a public issue. You can expect a reply within a week.
