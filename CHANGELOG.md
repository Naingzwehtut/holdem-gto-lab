# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-22

### Added

- Preflop range charts for 12 spots (6-max, 100bb) with mixed frequencies, hand explanations and equity against the opener.
- Range builder with drag painting and compact range text export.
- Spot analyzer: exact turn and river equity against a range, pot odds, EV of calling, MDF, range composition and a bet-sizing table.
- Equity calculator for up to six players holding cards, ranges or random hands, with exact enumeration where possible.
- Session review: PokerStars and GGPoker hand-history import, preflop grading against the charts, VPIP/PFR, and one-click analysis of every postflop decision.
- Screenshot scanner that reads cards from an uploaded image of a finished hand.
- Practice drills: preflop trainer, pot-math quiz and equity guessing.
- Eight interactive GTO lessons.
- Test suite, ESLint, Prettier, CI and GitHub Pages deployment.
